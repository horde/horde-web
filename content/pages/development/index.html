See how to get involved with Horde development. Whether you are developing an in-house custom application, or are interested in contributing to Horde find out how to get started, and where to find help.

Contribute

Want to get involved? The Horde Project is open to anyone interested in contributing - as a developer, packager, translator, or documentation writer.

See how to get started on dev.horde.org, our developer hub. It covers the project's Git repositories, the component/library directory, coding standards, and where to find help.

Looking for a specific standalone PHP library rather than a full Horde application? Browse the Component Directory on dev.horde.org.
