Development

See how to get involved with Horde development. Whether you are developing an in-house custom application, or are interested in contributing to Horde find out how to get started, and where to find help.

Libraries

Do you like some of the features our applications provide and would like to get similar functionality in your next PHP application? The Horde Project publishes a huge number of stand alone libraries that you can use in your own PHP development projects.

Contribute

Want to get involved? The Horde Project is open to anyone interested in contributing. See how to get started.

Source Code

Horde code may be obtained from a variety of sources, depending on your needs. If you intend to contribute to the project, you should clone our Git repository.

You may also browse our Git code tree directly online.

Versions

Being a mature project, there are quite a few older versions of our software. Horde 6 is the most recent version of the Application Framework and all new development is to be done against this.

See how the different versions of the various pieces of Horde fit together.
