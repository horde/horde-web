Groupware that runs anywhere, built on tools you can trust.

Horde is a free, open source webmail, calendar, contacts, and task suite. It's also the PHP library ecosystem underneath it, ready for you to build on. No vendor, no lock-in, just a project maintained by its community.

Deploy Horde Contribute

Why Horde

A groupware platform designed to be run by its users, not rented from a vendor.

📬

Full Groupware Suite

Webmail, calendar, contacts, tasks, notes, time tracking, and more - mature applications used by organizations for over two decades.

📱

Horde Everywhere

Responsive web UI, CalDAV/CardDAV/ActiveSync sync - access your data from desktop, mobile, or any standards-compliant client.

🧩

Open Source, Standards-Based

LGPL/GPL licensed, built on open protocols. Inspect it, extend it, self-host it - nothing is hidden behind a paywall.

🛠️

A Library Ecosystem

Horde's applications are built from independent PHP libraries you can reuse directly in your own projects - see what's under active development on dev.horde.org.
