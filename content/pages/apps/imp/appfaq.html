Does IMP support OAuth2 login to my mail server (Gmail, Office 365, etc.)?

Yes. IMP's IMAP/SMTP connections go through the Horde_Imap_Client library, which supports XOAUTH2/OAuthBearer authentication in addition to plain password auth. You configure an OAuth application/client with your provider and point IMP's backend configuration at it; exact steps depend on your Horde version and mail provider. See the IMP repository and Imap_Client repository for current configuration examples.

Can I run IMP against a non-IMAP backend, or read-only/archived mail?

IMP is IMAP/POP3-native. For anything else (e.g. Maildir without an IMAP server in front of it), you need an IMAP server layer - IMP itself does not speak Maildir/mbox directly.

Does IMP support multiple identities and per-identity signatures?

Yes - multiple identities (with independent From addresses, reply-to, and HTML/plain-text signatures) are a core IMP feature, configurable per user in preferences.
