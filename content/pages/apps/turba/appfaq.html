Can Turba sync with CardDAV clients (phones, Thunderbird, etc.)?

Yes - Turba exposes address books over CardDAV, so standard CardDAV clients can sync contacts directly with a Turba address book, in addition to the native web UI.

Can Turba use an existing LDAP directory instead of its own database?

Yes - Turba supports an LDAP backend/source alongside (or instead of) its SQL storage, so an existing corporate directory can be exposed read-only or read-write as a Turba address book, depending on configuration.

Can I have multiple address books with different sharing rules?

Yes - Turba supports multiple address books per user plus shared address books with the same permission model used across Horde (read/edit/delete/manage per user or group).
