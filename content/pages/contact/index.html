Contact

The best way to get in touch with the Horde Project depends on what you need.

Bugs, Features, and Development Discussion

For anything code-related - bug reports, feature requests, patches, or developer discussion - use one of:

  • GitHub Issues and Pull Requests (per-repository, under github.com/horde)
  • bugs.horde.org, the project's own bug tracker
  • lists.horde.org mailing lists, for developer and user-to-user discussion

Security Concerns

If you need to report a potential security issue, please contact security@horde.org and ralf.lang@gmail.com in parallel. This applies to security researchers and CVE Numbering Authorities alike.

Commercial & Consulting Inquiries

Horde is a full FOSS project, not an open-core product. See Commercial Use & Support for the full picture.
